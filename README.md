# Cart2Insight : Decoding E-Commerce Performance
A complete end‑to‑end e‑commerce analytics project designed to analyze business performance, customer behavior, seller efficiency, delivery operations, and customer satisfaction using the Olist E‑Commerce dataset.

Project Overview
Modern e‑commerce platforms generate massive amounts of data across orders, customers, sellers, products, payments, deliveries, and reviews.
This project transforms raw multi‑table e‑commerce data into meaningful business insights using:

Python

Pandas

SQL & MySQL

Statistics & Hypothesis Testing

Streamlit

Data Visualization

Feature Engineering

The goal is to build a fully functional analytics solution that supports data‑driven decision‑making.

Problem Statement
E‑commerce data is spread across multiple related tables, making it difficult to understand business performance directly from raw data.
This project aims to analyze the data and uncover insights related to:

Sales & revenue

Project Approach
Approach
Step 1: Understand the Business Problem
- Understand the business context
- Identify the key business objectives
- Define the questions the analysis should answer

Step 2: Understand the Dataset & ER Diagram
- Understand the 9 tables
- Identify primary and foreign keys
- Understand relationships between tables
- Prepare a data dictionary
- Create ER diagram

Step 3: Load the Raw Data
- Load all CSV files using Pandas
- Check shape, columns, and data types
- Understand the structure of each table

Step 4: Data Quality Analysis
- Identify missing values
- Check duplicates
- Check incorrect data types
- Identify inconsistent or invalid values
- Identify potential outliers
- Check primary-key uniqueness

Step 5: Data Cleaning & Preprocessing
- Handle missing values
- Remove duplicates
- Correct data types
- Format date/time columns
- Standardize categorical values
- Handle invalid records
- Rename columns where required

Step 6: Store Cleaned Data in SQL
- Create the database
- Create tables based on the ER diagram
- Load cleaned data into SQL
- Apply primary and foreign key constraints
- Verify the data after loading

Step 7: Feature Engineering
- Total order value
- Delivery days
- Delivery delay
- Customer order count
- Customer total spending
- Average order value
- Seller revenue
- Seller order count
- Repeat customer indicator

Step 8: Exploratory Data Analysis (EDA)
- Univariate analysis
- Bivariate analysis
- Multivariate analysis
- Trend analysis
- Correlation analysis
- Distribution analysis

Step 9: Statistical Analysis
T-Test — Delivery & Customer Satisfaction
ANOVA — Product Category & Spending
Chi-Square — Payment Method & Order Status

Step 10: SQL Analysis & Streamlit Dashboard
- Business Overview
- Sales Analysis
- Customer Analysis
- Seller & Product Analysis
- Delivery Analysis
- Customer Experience

Step 11: Generate Business Insights
Observation → Interpretation → Business Impact
